# 학년 통합 관리 시스템 (GradePlanner)

깃허브(GitHub)에 파일을 올려 사이트를 만들고, 파이어베이스(Firebase)에 자료를 저장하는 학년 업무용 웹앱입니다.
아래 순서대로 하나씩 따라 하면 누구나 자기 학교용 사이트를 만들 수 있어요.

- [1. 이 코드로 내 사이트 만들기](#1-이-코드로-내-사이트-만들기)
- [2. 보안을 위해 꼭 해야 할 일](#2-보안을-위해-꼭-해야-할-일)
- [3. 초기 비밀번호](#3-초기-비밀번호)

## 1. 이 코드로 내 사이트 만들기

### 준비물
- 이 코드 파일 묶음(gradeplanner.zip)
- 구글 계정(지메일 주소)
- 컴퓨터(크롬 브라우저를 추천해요)

### ① 깃허브 가입하기
1. 인터넷 주소창에 **github.com** 을 입력해서 들어가요.
2. 오른쪽 위의 **Sign up**(가입하기)을 눌러요.
3. 이메일, 비밀번호, **사용자 이름**을 입력해요.
   - 사용자 이름은 영어로 써요. 나중에 사이트 주소가 돼요. (예: `myschool6`)
4. 이메일로 온 숫자 코드를 입력하면 가입 끝!

### ② 깃허브에 저장소(파일 보관함) 만들기
1. 깃허브에 로그인해요.
2. 오른쪽 위 **＋** 버튼 → **New repository** 를 눌러요.
3. **Repository name**(이름)에 `gradeplanner` 처럼 영어 이름을 써요.
4. **Public**(공개)을 고르고, 아래 초록 버튼 **Create repository** 를 눌러요.

### ③ 파일 올리기
1. 내 컴퓨터에서 **gradeplanner.zip** 을 마우스 오른쪽 버튼 → **압축 풀기** 해요.
2. 깃허브 저장소 화면에서 **uploading an existing file** 글자를 눌러요.
3. 압축을 푼 `gradeplanner` 폴더를 열고, **그 안에 있는 파일과 폴더를 전부** 선택해서 깃허브 화면으로 끌어다 놓아요.
   - `index.html`, `version.json`, `manifest.webmanifest`, `assets` 폴더, `pages` 폴더 등이 모두 들어가야 해요.
   - `gradeplanner` 폴더 자체를 끌어다 놓으면 안 돼요. **폴더 안의 내용물**을 놓아요.
4. 맨 아래 초록 버튼 **Commit changes** 를 눌러요.

### ④ 사이트 켜기
1. 저장소 위쪽 메뉴에서 **Settings**(설정)를 눌러요.
2. 왼쪽 메뉴에서 **Pages** 를 눌러요.
3. **Branch** 에서 `main` 을 고르고, 옆 칸은 `/(root)` 를 고른 뒤 **Save** 를 눌러요.
4. 1~2분 기다린 뒤 새로고침하면 위쪽에 사이트 주소가 나와요.
   - 주소 모양: `https://사용자이름.github.io/저장소이름/`
   - 이 주소를 적어 두세요. 이게 내 사이트예요!
   - 아직 자료 저장소(파이어베이스)를 연결하지 않아서, 지금 열면 제대로 동작하지 않아요. 아래 단계를 계속해요.

### ⑤ 파이어베이스 가입하고 프로젝트 만들기
1. 주소창에 **console.firebase.google.com** 을 입력하고 구글 계정으로 로그인해요.
2. **프로젝트 만들기**(또는 "Firebase 프로젝트 시작하기")를 눌러요.
3. 프로젝트 이름을 써요. (예: `myschool`)
4. 구글 애널리틱스는 **꺼도 돼요.** → **프로젝트 만들기**
5. 만들어지면 **프로젝트 ID**(예: `myschool-1234`)를 적어 두세요.

### ⑥ 웹 앱 등록하기
1. 프로젝트 첫 화면에서 **`</>`**(웹) 모양 아이콘을 눌러요.
2. 앱 이름을 아무거나 쓰고 **앱 등록** 을 눌러요. ("Firebase 호스팅"은 체크하지 않아요.)
3. 화면에 `firebaseConfig = { ... }` 라는 글이 나와요. 그 안의 값들을 메모장에 복사해 두세요.
   - `apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`
   - 나중에 다시 보고 싶으면: 왼쪽 위 톱니바퀴 ⚙ → **프로젝트 설정** → 아래쪽 **내 앱**

### ⑦ 데이터베이스(자료 저장소) 만들기
1. 왼쪽 메뉴에서 **빌드(Build)** → **Firestore Database** 를 눌러요.
   - 메뉴가 안 보이면 왼쪽 위 ☰ 를 눌러 펼치거나, 맨 아래 **모든 제품 보기** 를 눌러요.
2. **데이터베이스 만들기** 를 눌러요.
3. 위치는 아무거나 골라도 돼요. (한 번 정하면 바꿀 수 없어요.)
4. **테스트 모드로 시작** 을 고르고 만들기를 눌러요.
   - 테스트 모드는 잠깐 쓰는 설정이에요. 아래 **2번 보안 설정**에서 꼭 바꿔요.

### ⑧ 로그인 기능 켜기
1. 왼쪽 메뉴 **빌드** → **Authentication** → **시작하기** 를 눌러요.
2. **로그인 방법** 탭 → **새 제공업체 추가** → **이메일/비밀번호** 를 눌러요.
3. 맨 위 **이메일/비밀번호** 스위치를 켜고 **저장** 해요. (아래 "이메일 링크"는 켜지 않아요.)
4. 다시 **새 제공업체 추가** → **Google** → 스위치 켜기 → 지원 이메일을 고르고 **저장** 해요.
   - 구글 스프레드시트로 내보내기 기능에 필요해요.
5. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `사용자이름.github.io` 를 넣고 추가해요.

### ⑨ 코드에 내 파이어베이스 넣기 (파일 딱 하나만!)
1. 깃허브 저장소에서 `assets` → `js` → **`firebase-config.js`** 파일을 눌러 열어요.
2. 오른쪽 위 **연필 모양(편집)** 버튼을 눌러요.
3. `window.FIREBASE_CONFIG = { ... }` 안의 값들을 ⑥에서 복사한 내 값으로 바꿔요.
   - 따옴표(`"`)와 쉼표(`,`)는 지우지 말고, 따옴표 **안의 글자만** 바꿔요.
4. 초록 버튼 **Commit changes** 를 눌러 저장해요.
5. 다른 파일은 고치지 않아도 돼요. 로그인 계정 주소와 보안 규칙이 이 값에 맞게 자동으로 맞춰져요.

### ⑩ 처음 열어 보기
1. ④에서 적어 둔 내 사이트 주소로 들어가요.
2. 왼쪽 위 ☰ 메뉴 → **학년 관리자** 를 눌러요.
3. 아래 **3번의 초기 비밀번호** 로 로그인해요.
4. 학년도, 학년, 학급, 교시 등을 설정해요.
5. 이어서 **바로 아래 2번 보안 설정을 꼭 해요!**

> 💡 나중에 코드를 고쳐서 다시 올릴 때는 `version.json` 파일도 꼭 함께 올려요. 그래야 모든 기기가 새 버전을 받아요.

## 2. 보안을 위해 꼭 해야 할 일

학생 명렬표, 쇼핑몰 ID 같은 개인정보가 있으니 **반드시** 해 주세요. **순서가 중요해요.**

1. **로그인 기능 켜기** — 1번의 ⑧(이메일/비밀번호 켜기)을 먼저 해요.
2. **학년 관리자에 한 번 로그인** — 사이트의 학년 관리자에 초기 비밀번호로 로그인해요.
   - 이때 자동으로 "보안 전환"이 돼요. (비밀번호를 파이어베이스 로그인 계정으로 옮겨요.)
3. **보안 규칙 넣기** — 2번을 마치면 **바로 이어서** 해요.
   1. 학년 관리자 → **비밀번호/데이터 관리** 탭 → **보안 상태** 칸에서 **보안 규칙 복사** 버튼을 눌러요.
   2. 파이어베이스 → **Firestore Database** → **규칙** 탭으로 가요.
   3. 원래 있던 글을 **모두 지우고** 복사한 내용을 붙여 넣은 뒤 **게시** 를 눌러요.
   - 저장소에 있는 `firestore.rules` 파일은 참고용이에요. 직접 붙여 넣지 말고 꼭 **보안 규칙 복사** 버튼을 써요. (내 프로젝트 주소가 자동으로 채워져요.)
   - 다른 학년으로 바꾸기 전에 이 단계를 꼭 마쳐요.
4. **확인하기** — 보안 상태 칸에 초록색 **✔ 두 개** 가 보이면 성공이에요.
5. **새 계정 만들기 막기** — 파이어베이스 → **Authentication** → **설정** 탭 → **사용자 작업** → **생성(가입) 사용** 을 꺼요.
   - 다른 사람이 로그인 계정을 새로 만들 수 없게 해요. (꼭 2번을 마친 다음에 꺼요.)
6. **초기 비밀번호 바꾸기** — 학년 관리자 → 비밀번호/데이터 관리 → **비밀번호 변경**
   - "지금 관리자 비밀번호"와 새 비밀번호를 입력해요. 새 비밀번호는 **6자 이상**이에요.
   - 페이지 접근 비밀번호와 관리자 비밀번호는 **서로 다르게**, 숫자와 영어를 섞으면 더 안전해요.

**보안 설정을 마치면 이렇게 돼요**
- 학생 명렬표, 쇼핑몰 ID, 내선번호 파일, 특별실 비밀번호는 비밀번호로 로그인한 사람만 볼 수 있어요.
- 시간표와 일정은 지금처럼 누구나 보고 고칠 수 있어요.
- 로그인은 다른 메뉴로 옮기거나, 새로고침하거나, 20분 동안 아무것도 안 하면 자동으로 풀려요.

## 3. 초기 비밀번호

| 구분 | 초기 비밀번호 |
|---|---|
| 페이지 접근 비밀번호 (명렬표·내선번호·쇼핑몰 ID·특별실 비밀번호) | `000000` |
| 관리자 비밀번호 (학년 관리자) | `000000` |

- 처음 설치했을 때의 기본값이에요. **사이트를 쓰기 시작하면 바로 바꿔 주세요.** (2번의 6단계)
- 비밀번호는 **6자리 이상**으로 정해야 해요.
