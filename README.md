# 6학년 통합 관리 시스템 (GitHub Pages + Firebase)

구글 사이트/앱스스크립트/스프레드시트 웹앱을 GitHub Pages + Firebase(Firestore, Storage)로 옮긴 버전입니다.

## 배포
1. 이 폴더 전체를 GitHub 저장소에 올립니다.
2. 저장소 Settings > Pages > Branch `main` / `(root)` 로 설정합니다.
3. Firebase 콘솔에서 Firestore Database / Storage 를 만들고, `firestore.rules`, `storage.rules` 내용을 각각 규칙에 붙여넣어 게시합니다.
4. Authentication > 설정 > 승인된 도메인에 `<아이디>.github.io` 를 추가합니다.

## 구조
- `index.html` : 메뉴 + 페이지 표시(기존 구글 사이트 역할)
- `pages/` : 각 화면. 기존 화면 코드를 그대로 쓰고 데이터만 Firebase로 연결
- `assets/js/gas-shim.js` : `google.script.run` 호출을 Firestore/Storage로 바꿔주는 연결 코드
- `scripts/port_pages.py` : 기존 화면을 변환한 스크립트(참고용)

## Firestore 컬렉션
엑셀 탭과 동일: data_basic, data_task_school, data_task_memo, data_student, data_sub_timetable,
data_add_timetable, data_gym_timetable, data_room_timetable, data_budget, data_supply
새로 쓰는 컬렉션: app_config(설정·비밀번호), data_overview(개요 표 수기 칸), data_basic_timetable,
data_mall(쇼핑몰 ID), data_links(바로가기)

## 관리자 페이지 (pages/admin.html)
초기 비밀번호는 관리자·페이지 접근 모두 `0000` 입니다. (비밀번호/데이터 관리 메뉴에서 변경)
- 시간표 설정: 과목·시수·전담 체크(`data_basic.list_sub`, `list_sub_hours`, `list_sub_special`), 교시(`list_time`)
- 학년 기초 설정: 학년도, 학기·방학, 기초 일정(CSV 업로드), 학급·담임·전담교사(`app_config/general`, 교사 이름은 `list_t`)
- 공간 개방 설정: 체육 공간(`list_gym`)·특별실(`list_room`), 학기별 개방 시간, 예외(`app_config/space_open`)
- 비밀번호/데이터 관리: 공통 비밀번호(`app_config/passwords`), 학년도별 데이터 삭제

## 참고
- 목록 필드는 순서를 보존하려고 `<필드>_order` 숫자 필드를 함께 저장합니다.
- 날짜는 기존 데이터와 같은 문자열(예: `2026년 10월 20일 (화)`)로 저장합니다.

## 전담 시간표 / 특별실 시간표
- 전담 시간표: 관리자 > 학년 기초 설정 > 전담교사에 등록한 (과목, 교사) 마다 탭이 만들어지고, 표에는 그 교사의 담당학급만 나옵니다.
- 특별실 시간표: 관리자 > 공간 개방 설정의 공간 목록, 학기별 개방 시간, 예외(닫힌 곳 열기/열린 곳 닫기)를 그대로 따릅니다.
- 공휴일은 법령 기준으로 계산합니다(양력 고정일, 음력 명절은 천문 계산, 대체공휴일). 선거일·임시공휴일은 관리자 > 학년 기초 설정 > 기초 일정(휴일 체크, CSV의 '휴일 여부' 열) 또는 개요 화면 연필 아이콘에서 입력하며 `data_basic` 의 `holiday`, `holiday_start_date`, `holiday_end_date` 에 저장됩니다.

## 관리자 페이지 동작
- 관리자 페이지는 들어올 때마다 비밀번호를 묻습니다.
- 시간표 설정, 학급·교사 설정, 학기·방학 날짜, 체육 공간/특별실 목록과 개방 설정은 입력하면 바로 저장됩니다. (저장 버튼 없음)
- 담임교사·전담교사 이름은 `data_basic.list_t` 에 중복 없이 저장되고, 학급/과목/기간과의 매칭은 `app_config/general`(homerooms, specials)에 저장됩니다.
- 과목별 1학기·2학기 총시수는 `data_basic` 의 `list_sub_hours_sem1`, `list_sub_hours_sem2` 에 저장되고, 전담 시간표 상단의 '시수' 줄에 표시됩니다.

## 화면 구성 / 속도
- 메인 화면(index.html)은 왼쪽 메뉴를 햄버거(☰) 버튼으로 접어 두고, 제목은 관리자 > 학년 기초 설정의 학년도·학년을 따라갑니다.
- React 화면(명렬표, 기초·월간·전담·특별실 시간표)은 미리 컴파일해 두어 Babel/React CDN 없이 `assets/js/react.min.js` 하나로 동작합니다.
- 웹폰트를 쓰지 않고 기기 기본 한글 글꼴을 사용합니다.
- `scripts/port_pages.py` 는 기존 앱스스크립트 화면을 변환·컴파일하는 스크립트입니다. (다시 만들 때만 필요)

## 전담 시간표 / 반별 일정 / 강좌별 시간표
- 전담 시간표 상단 제목 옆 연필: 공간 이름을 입력하면 `과학 김과학/과학실1` 처럼 표시되고 `app_config/general.specials[].space` 에 저장됩니다.
- 반별 일정 조회: 날짜·교시·내용이 같은 일정은 반을 묶어 하나로 보여 주고 함께 수정·삭제합니다. 전담 과목 일정은 `data_sub_timetable` 을 고치며, 같은 교사의 다른 반 또는 같은 반의 일정과 겹치면 안내 후 저장하지 않습니다.
- 강좌별 시간표: 연필 아이콘으로 강좌 범주를 만들면 드롭다운 맨 위에 파란 볼드로 고정됩니다. (`app_config/course_groups`)

## Firestore 사용량(읽기) 줄이기
- Firestore 무료 한도는 하루 읽기 5만 건입니다. 컬렉션을 통째로 읽으면 화면을 열 때마다 수천 건이 소모되므로, 다음 방식을 씁니다.
  1. 컬렉션별 "변경 번호"를 `app_meta/version` 문서 1건에 둡니다. 화면을 열면 이 문서 1건만 읽습니다.
  2. 번호가 같으면 기기(localStorage)에 저장한 사본을 쓰고, 달라진 컬렉션만 새로 받습니다.
  3. 이 앱에서 저장하면 번호를 올리고 사본도 같이 고쳐서, 저장 직후 다시 읽지 않습니다.
- 파이어베이스 콘솔에서 데이터를 직접 고쳤다면 관리자 > 비밀번호/데이터 관리 > "모든 기기 데이터 새로고침"을 누르세요.
- 안전장치로 사본은 6시간이 지나면 번호가 같아도 다시 받습니다.

## 학년도별로 따로 저장되는 설정
- 담임·전담교사 매칭: `app_config/year_<학년도>`, 공간 개방 설정(체크·예외): `app_config/space_open_<학년도>`
- 학년도를 바꾸면 새 학년도는 비어 있는 상태로 시작하고, 이전 학년도 설정은 그대로 보관됩니다. (학급 수·이름, 학년은 공통)
- 데이터 삭제에서 학년도를 지우면 이 두 문서도 함께 삭제됩니다.

## 학년도 데이터 삭제 기준
- 날짜로 구분되는 데이터: 학교 행사, 학년 일정, 추가된 일정, 체육 공간·특별실·전담 시간표, 학기·방학·휴일 설정, 학습준비물(연도), 담임·전담교사 매칭, 공간 개방 설정
- 작성일이 그 학년도(2월 1일~다음 해 2월 말일)인 데이터: 학생 명렬표, 개요 비고, 예산, 강좌 범주, 이미지·파일(예산 비고 첨부 포함)
  - Firestore 문서의 작성일은 REST API의 `createTime`(처음 만든 시각), 파일은 Storage의 `timeCreated`, 강좌 범주는 항목별 `createdAt` 을 씁니다.
  - 작성일을 하나라도 확인하지 못하면 아무것도 삭제하지 않고 오류를 안내합니다.
- 삭제되지 않음: 쇼핑몰 ID, 바로가기, 비밀번호, 학급·과목·교시·공간 목록
- 개요 비고는 학년도별 문서(`data_overview/r5_<학년도>`)에 저장됩니다.

## 학급 기초 시간표 (pages/timetable-basic.html)
- 학급 탭은 관리자 > 학년 기초 설정의 **학급 수**만큼, 교시 행은 관리자 > 시간표 설정의 **교시 설정**만큼 만들어집니다.
- 과목을 넣을 수 있는 칸은 관리자 > 시간표 설정 > **주간시수배정**(요일×교시 체크박스)에서 체크한 칸입니다. 저장값이 없으면 모든 칸이 켜져 있고, 꺼 둔 칸만 `app_config/basic_slots` 에 기록됩니다. 요일/교시 머리글을 누르면 한 줄이 한꺼번에 켜지고 꺼집니다.
- 학급 화면 제목 오른쪽의 마법봉 아이콘(휴지통 옆)은 "빈 공간을 자동으로 채웁니다." 확인 후 켜진 빈 칸에 남은 배정시수만큼 과목을 넣습니다. 이미 입력한 칸은 바꾸지 않고, 같은 과목이 한 요일·연속 교시에 몰리지 않게 하며, 전담 과목은 다른 반과 같은 시간이 되지 않게 피합니다.

## 예산 페이지 (pages/budget.html)
- 탭: **학년 예산**, **학습준비물**, 그리고 `+` 로 추가한 예산 페이지. 추가할 때 예산명(버튼 이름)과 1행 머리글을 입력합니다. 추가 페이지의 줄은 `data_sheet_rows`, 페이지 정의는 `app_config/budget_sheets` 에 저장되며 삭제 기준(작성일)에 포함됩니다.
- 표는 구글 스프레드시트처럼 칸을 눌러 바로 고치면 자동 저장됩니다. 맨 아래 빈 줄에 입력하면 새 줄이 생기고, 줄 번호에 마우스를 올리면 삭제(✕)가 나타납니다. 여러 칸을 복사해 붙여넣을 수 있고 Enter/Tab/방향키로 이동합니다.
- 새로 만든 줄은 `row_order` 로 맨 아래에 놓입니다. (기존 줄은 이전처럼 문서 ID 순서)

## 예산 내보내기
- 엑셀로 내보내기: 로그인 없이 바로 .xlsx 를 내려받습니다. (외부 라이브러리 없이 `assets/js/xlsx-lite.js` 가 파일을 만듭니다.)
- 구글 스프레드시트로 내보내기: 구글 로그인(Firebase Auth) 후 사용자의 구글 드라이브에 새 스프레드시트를 만듭니다. 권한은 `drive.file`(이 앱이 만든 파일만)입니다.
  - 사용 전 설정(한 번만): Firebase 콘솔 > Authentication > 로그인 방법에서 Google 사용 설정, 승인된 도메인에 `<아이디>.github.io` 추가, Google Cloud 콘솔(프로젝트 gradeplanner-d5499)에서 Google Sheets API 사용 설정
- 현재 보고 있는 탭(예산 내역 / 학습준비물)과 필터가 그대로 내보내집니다. 금액·합계는 수식이고, 예산 내역에는 "예산 현황" 시트가 함께 들어갑니다.

## 이번 수정 사항 (전담·특별실·예산 등)
- **전담시간표**: 상단 시수편차 표는 화면이 아무리 커져도 최대 1230px(데스크탑 기본 너비 기준 약 2/3)까지만 커집니다.
- **특별실 시간표**: 비밀번호는 목록에 추가/삭제하면 바로 저장되고, 체육공간·컴실 등은 반을 입력하면 바로 저장됩니다(저장 버튼 없음). 요일 표는 데스크탑에서 가로 스크롤이 생기지 않습니다(모바일 폭에서만 스크롤).
- **시간표 이미지 업로드**: 업로드 전에 긴 변 1600px / JPEG로 줄이고, Storage 실패 시 20초 안에 원인 안내를 띄웁니다. 계속 느리면 Firebase 콘솔 > Storage가 시작되어 있는지, `storage.rules`가 게시되었는지 확인하세요.
- **반별 시간표**: 같은 날짜·같은 이름·같은 반 구성이면 여러 교시를 한 항목으로 묶어 함께 수정합니다.
- **월간 시간표**: 처음 열 때 오늘 날짜의 달이 선택됩니다.
- **예산**: 줄 왼쪽 번호칸에 마우스를 올리면 ⠿(끌어서 순서 변경, 데스크탑) 🎨(줄 색깔) ✕(삭제)가 나타납니다. 위쪽 A·B·C 칸 경계를 끌어 열 너비를 바꿀 수 있고(전체 너비는 유지), 너비·줄 색·순서는 모두에게 공유됩니다(`app_config/budget_cols`, 각 행의 `row_color`/`row_order`).

## 추가 수정 (일정 묶음·명렬표 등)
- **홈/개요 일정**: 강사 일정은 같은 이름끼리만 한 줄로 묶습니다(예: `7반 1교시, 2교시 우쿨(11~12)` / `7반 4교시 튜터(11)`). 정렬은 교시 → 반 순서입니다.
- **컴실 등(특별실)** 일정이 월간 시간표·반별 일정 조회에 체육 공간과 같은 방식으로 반영됩니다.
- 전담 시간표 시수편차 표는 가운데 정렬, 특별실 시간표의 `특별실 시간표` 탭은 `시간표 이미지`로 이름을 바꿨습니다.
- 특별실 비밀번호 화면은 닫기 버튼·안내문이 없고, 다른 탭에 갔다 오면 비밀번호를 다시 묻습니다.
- **명렬표**: 관리자 버튼 삭제, 반별 명렬표 표는 최대 절반 너비(번호·성별 열은 2글자 폭, 생년월일은 16글자 폭), 학년 전체/반별/전체 반 엑셀 다운로드(남·여 색 유지).
### Firebase Storage 시작하기
1. console.firebase.google.com > 프로젝트 `gradeplanner-d5499` > 왼쪽 메뉴 **빌드 > Storage** > **시작하기**
2. 위치(예: asia-northeast3 서울) 선택 후 완료. (일부 계정은 Blaze 요금제 전환을 요구하는데, 소규모 사용은 무료 한도 안입니다.)
3. Storage > **규칙** 탭에 `storage.rules` 내용을 붙여넣고 **게시**.

## 추가 수정 (모바일·공간 데이터 정리 등)
- **삭제된 공간의 데이터**: 월간·반별 시간표는 현재 공간 목록에 있는 공간의 데이터만 보여 줍니다. 관리자 > 공간 개방 설정에서 공간을 지울 때 입력된 시간표도 함께 지울지 묻고, 화면 위쪽 `삭제된 공간의 남은 데이터` 카드에서 남은 데이터를 개별/전체 삭제할 수 있습니다. 공간 이름을 바꾸면 입력된 시간표도 새 이름으로 옮겨집니다.
- 관리자 페이지: 불러오기 실패·지연 시 오류와 `다시 시도` 버튼을 보여 줍니다. 이미 지워진 문서를 고치려 할 때 저장이 실패하던 문제를 막았습니다.
- 학년 개요: 표의 `계` 열은 데스크톱에서 학급 열의 1.5배, 전체 일정 표는 모바일에서 최소 너비를 유지(가로 스크롤), 연필 버튼 터치 대응.
- 명렬표 엑셀: 항목(번호·이름·성별·기타·생년월일)과 체크리스트 열 개수를 선택해서 내려받습니다.
- 특별실 시간표·기초시간표·반별 명렬표의 모바일 표 너비/글자 크기 조정.

## 추가 수정 (명렬표·공간 데이터)
- **명렬표**: 학년 전체/반별 반 수는 관리자 > 학급 수를 따릅니다. 새로고침 버튼과 `n반 명렬표` 제목줄을 없앴고 반 버튼줄은 스크롤해도 고정됩니다. 반별 표의 열 너비는 넓은 화면에서만 최대값으로 고정되고 좁아지면 비율로 줄어듭니다. 성별 표기는 `남/남자/남성`, `여/여자/여성`을 모두 같은 성별로 취급합니다(줄 색·학년 개요 인원수).
- **엑셀 업로드**: 명렬표 페이지의 `⬆ 엑셀 업로드` (시트 이름 `1반`…, 머리글 번호·이름·성별·기타·생년월일). `예시 파일 받기`로 양식을 내려받을 수 있습니다. 올린 파일에 들어 있는 반의 기존 명단은 파일 내용으로 바뀝니다.
- **삭제된 공간의 데이터**: 삭제하기 전까지 월간·반별 시간표에 계속 표시됩니다. 관리자에서 공간을 지우면 입력된 시간표 목록이 팝업으로 뜨고, 선택한 항목만 삭제할 수 있습니다(남긴 것은 `삭제된 공간의 남은 데이터` 카드에서 나중에 정리).

## 스프레드시트로 내보내기
엑셀 내보내기가 있는 곳(예산, 명렬표)에는 `구글 스프레드시트로 만들기`도 있습니다(`assets/js/gsheet-export.js`). 처음 쓰려면 Firebase 콘솔 > Authentication > 시작하기 > 로그인 방법에서 Google을 사용 설정하고, Google Cloud 콘솔에서 `Google Sheets API`를 사용 설정해야 합니다.

## 시간표 이미지 저장 방식 변경
특별실 시간표 이미지는 Firebase Storage 대신 Firestore(`data_images` 컬렉션)에 압축한 사진으로 저장합니다(Blaze 요금제 불필요).
업로드 시 약 300KB 이하가 되도록 크기·품질을 낮추며(최대 1600px, JPEG), 한 장당 700KB를 넘으면 거부합니다.
비고 첨부(예산)·학급문고·확장 파일은 아직 Storage를 사용합니다.

예산 비고 첨부도 Firestore(`data_files`)에 저장합니다(사진은 자동으로 약 300KB로 축소, 그 밖의 파일은 700KB까지).
엑셀/스프레드시트 내보내기의 링크 칸은 주소 전체를 글자로 보여 주고 같은 주소로 하이퍼링크를 겁니다.

## 예산 페이지 추가 변경
- 비고 첨부 아이콘은 🖼(첨부 없음: 회색·반투명, 있음: 선명). 엑셀/스프레드시트 내보내기에는 비고 오른쪽에 "첨부이미지" 칸을 덧붙여 사진 축소본(긴 변 240px)을 넣습니다(줄당 최대 5장). 구글 스프레드시트에서는 `=IMAGE("data:...")` 수식을 사용합니다.
- 예산 카드 맨 끝의 "⚙ 관리자" → 관리자 비밀번호 확인 후 학년 관리자 > 예산 설정으로 이동(다시 묻지 않음).
- 예산 설정(`list_budget`, `list_budget_amount`, `list_budget_color`, `list_budget_order`): 카드 끌어서 순서 변경, 🎨 배경색(기본 5색은 특별실과 동일), ✏️ 이름·배정액 수정(이름을 바꾸면 예산 표의 기존 내역도 새 이름으로), + 추가, 수정창에서 삭제.
- 예산 표: 맨 아래 빈 줄 + 그 아래 + 버튼(빈 줄 5개씩 추가).

## 예산 카드 표시 페이지
- 관리자 > 예산 설정: 카드마다 "표시할 예산 페이지"(학년 예산/학습준비물/추가한 예산 페이지)를 고르고(`list_budget_pages`), 페이지별 카드 순서는 `app_config/budget_layout`에 저장됩니다. 보기 탭: 전체 / 각 페이지.
- 모든 예산 페이지(학습준비물, 추가 페이지 포함) 상단에 카드 구역과 "⚙ 관리자" 버튼이 있습니다.
- 사진이 들어간 구글 스프레드시트 내보내기는 사진 포함 엑셀을 드라이브에 올려 구글 시트로 변환합니다(Google Drive API 사용 설정 필요).

## 성능 관련 구조 (모바일/시크릿 모드)
- Tailwind CDN 대신 미리 만든 CSS(`assets/css/tw-base.css`, `tw-util.css`)를 사용합니다. 클래스를 새로 쓰면 `node scripts/build_css.mjs`(tailwindcss 필요)로 다시 만드세요.
- Firebase SDK/연결은 상위 창(index.html)이 한 번만 초기화하고 각 페이지(iframe)가 공유합니다(`assets/js/fb-boot.js`).
- 시크릿 모드에서는 localStorage가 유지되지 않으므로, 앱을 켜 둔 동안은 메모리 캐시(`parent.__gpMem`)로 Firestore 읽기를 줄입니다.
- 저장은 변경 번호 갱신을 같은 묶음(batch)에 넣어 통신 횟수를 줄였습니다.
- 바로가기: 이름/URL/메모(선택)를 한 팝업에서 입력합니다.
